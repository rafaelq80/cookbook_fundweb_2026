<h3>1.1. Visão Geral do Projeto</h3>



O **Projeto Portfólio** consiste em um **portfólio profissional moderno para uma pessoa desenvolvedora**, projetado para apresentar informações pessoais, projetos e formas de contato de maneira clara, organizada e responsiva. O site é composto pelos seguintes recursos e funcionalidades:

- **Fluxo de navegação fluido e organizado**, com menu fixo, rolagem suave e separação clara das seções

<h2>👣 Passo 01 - Criar o arquivo .gitignore</h2>



Vamos criar o arquivo **`.gitignore`** para definir **quais pastas e arquivos não devem ser versionados pelo Git**.
Esse arquivo será criado dentro da pasta **portfolio** e tem como objetivo evitar que arquivos de configuração do ambiente de desenvolvimento e outros itens desnecessários sejam enviados para o repositório.

Essa prática é importante para:

- Manter o repositório mais limpo e organizado
- Evitar conflitos entre diferentes ambientes de desenvolvimento
- Versionar apenas os arquivos essenciais do projeto

No nosso caso, o **`.gitignore`** será utilizado principalmente para ignorar:

- A pasta de configurações do **Visual Studio Code**
- Arquivos temporários ou específicos do sistema operacional
- Outros arquivos que não fazem parte do código do projeto

Com isso, garantimos um versionamento mais profissional e alinhado às boas práticas de desenvolvimento.

1. Na **Barra Explorer**, selecione a pasta **portfolio** e clique no botão **New File** (Novo Arquivo), indicado na imagem abaixo:

Cada grupo de regras evita o versionamento de arquivos **gerados automaticamente**, **específicos do ambiente local** ou **sensíveis**, como dependências, caches, logs, builds e variáveis de ambiente. Dessa forma, o repositório permanece mais limpo, seguro e padronizado, garantindo que apenas o código-fonte essencial seja compartilhado entre todas as pessoas desenvolvedoras, independentemente do editor, do sistema operacional ou das tecnologias auxiliares utilizadas no projeto.

<h2>👣 Passo 05 - Escrever o Código HTML</h2>



Vamos começar montando a estrutura básica da nossa página. Insira o trecho de código abaixo no arquivo **index.html** 

```html
<!DOCTYPE html>
<html lang="pt-br">
<head>
    
    <meta charset="UTF-8">
	
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
	
    <meta name="author" content="Generation Brasil">
    <meta 
        name="description"
        content="Portfólio da Generation Brasil, 
                desenvolvedor Full Stack especializado em criar experiências 
                digitais incríveis. Conheça meus projetos e entre em contato."
    >
    <meta name="robots" content="index, follow">

    <link rel="icon" type="image/svg+xml" href="./assets/img/favicon.svg">

    <title>Portfólio Generation Brasil</title>
</head>
<body>
    
</body>
</html>
```

O código acima representa a **estrutura básica de uma página HTML**, conforme visto no conteúdo **Estrutura Básica de uma Página HTML**.

Observe que foram adicionadas **três meta tags importantes**:

- **description**: utilizada para definir uma descrição breve e objetiva sobre o conteúdo da página;
- **author**: utilizada para informar o nome do autor ou responsável pela página;
- **robots**: utilizada para indicar aos mecanismos de busca como a página deve ser tratada, por exemplo, se pode ser indexada e se seus links podem ser seguidos.

Essas três meta tags, em conjunto com a meta tag **charset** e a tag **title**, são fundamentais para a configuração inicial do **SEO (Search Engine Optimization)** da página.

> **SEO (Search Engine Optimization)**, ou **Otimização para Mecanismos de Busca**, é um conjunto de técnicas utilizadas para melhorar o posicionamento de um site nos resultados de buscadores, como o Google.
>
> Um bom SEO torna a página mais visível para os usuários e aumenta as chances de atrair **tráfego orgânico**, ou seja, visitas que não dependem de anúncios pagos.
>
> Quanto melhor for o SEO da página, maior será a probabilidade de ela aparecer entre os **primeiros resultados** quando alguém pesquisar por temas relacionados ao conteúdo que o site oferece.
>
> Para mais detalhes, veja o conteúdo sobre **[SEO](10.md)**.

O uso correto das meta tags desde o início do desenvolvimento contribui para uma base sólida, organizada e alinhada às boas práticas de desenvolvimento web e SEO.
