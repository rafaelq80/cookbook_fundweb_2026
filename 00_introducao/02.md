<h2>1. Visual Studio Code</h2>



O **Visual Studio Code** é um **editor de código-fonte** desenvolvido pela Microsoft, amplamente utilizado no desenvolvimento de aplicações que envolvem diferentes **linguagens de programação**, **bibliotecas** e **frameworks**. Ele se destaca pela leveza, flexibilidade e forte suporte ao desenvolvimento **web**, sendo uma das ferramentas mais populares entre pessoas desenvolvedoras nesse ecossistema.

Embora seja comum encontrar o termo “IDE” associado ao Visual Studio Code, tecnicamente ele é classificado como um **editor de código extensível**, que pode se comportar como uma IDE por meio da instalação de extensões.

<div align="center">
  <img src="https://i.imgur.com/0np1BW1.png" title="source: imgur.com" width="70%"/>
</div>



> Um **Ambiente de Desenvolvimento Integrado (IDE)** é um software utilizado para criar aplicações que reúne, em uma única interface gráfica (GUI), diversas ferramentas necessárias ao desenvolvimento. Normalmente, uma IDE inclui:
>
> - **Editor de código-fonte**: permite escrever e editar código com recursos como destaque de sintaxe, autocompletar, formatação automática e identificação de erros durante a digitação.
> - **Ferramentas de automação de build**: automatizam tarefas repetitivas, como compilação, empacotamento da aplicação e execução de testes.
> - **Depurador (Debugger)**: possibilita executar o código passo a passo, inspecionar variáveis e identificar falhas de lógica durante a execução do programa.

O **Visual Studio Code** oferece excelente suporte ao desenvolvimento de **websites utilizando HTML, CSS e JavaScript**, sendo amplamente adotado na criação de páginas e aplicações para a web. Ele reúne recursos que facilitam tanto a construção da estrutura da página quanto a estilização e a implementação de comportamentos interativos.

Entre os principais recursos disponíveis para o desenvolvimento web, destacam-se:

- **Suporte nativo a HTML, CSS e JavaScript**: com destaque de sintaxe, autocompletar, formatação automática e validação básica de erros, tornando o processo de escrita do código mais rápido e seguro;
- **Pré-visualização e testes no navegador**: por meio de extensões, é possível visualizar o website em tempo real enquanto o código é alterado, facilitando ajustes visuais e de comportamento;
- **Integração nativa com Git**: permite gerenciar versões do código diretamente pelo editor, facilitando o controle de alterações, commits e a sincronização com repositórios remotos;
- **Ferramentas de depuração**: possibilitam analisar a execução do JavaScript no navegador, auxiliando na identificação de erros de lógica e problemas de funcionamento das páginas.

Graças à sua arquitetura baseada em extensões, o Visual Studio Code pode ser facilmente adaptado às necessidades do desenvolvimento web, oferecendo uma experiência próxima à de uma IDE completa, sem abrir mão da leveza, simplicidade e bom desempenho.

Além do **Visual Studio Code**, existem outras IDE's voltadas para o desenvolvimento web:

| IDE / Editor     | Descrição                                                    |
| ---------------- | ------------------------------------------------------------ |
| **Sublime Text** | Editor de código rápido e sofisticado, conhecido pela alta performance e interface limpa. Possui suporte a HTML, CSS e JavaScript, com recursos como múltiplos cursores, preenchimento automático e personalização por plugins. É pago, mas oferece versão de avaliação gratuita. |
| **Komodo IDE**   | Ferramenta com um conjunto completo de recursos para desenvolvimento web. Suporta HTML, CSS e JavaScript, além de integração com depurador, controle de versões e suporte a outras linguagens. É uma opção open source. |
| **WebStorm**     | IDE completa voltada para o desenvolvimento web moderno. Oferece suporte avançado a HTML, CSS e JavaScript, com ferramentas inteligentes de refatoração, depuração e integração com frameworks front-end. É uma ferramenta paga, indicada para projetos mais complexos. |

<h2>👣 Passo 02 - Configurando o Terminal do Visual Studio Code</h2>



Neste passo, vamos configurar o Visual Studio Code para utilizar o **Git Bash** como Terminal padrão:

1. Depois de abrir a pasta, abra o **Terminal** do Visual Studio Code através do menu **Terminal 🡪 New Terminal (Terminal 🡪 Novo Terminal)**

<div align="center"><img src="https://i.imgur.com/4rdobXK.png?1" title="source: imgur.com" /></div>

2. Será aberta a tela do **Power Shell** na parte inferior da janela do Visual Studio Code.

<div><img src="https://i.imgur.com/rgwPNOV.png" title="source: imgur.com" /></div>

3. Ao lado do identificador do Terminal **powershell**, tem um botão com um sinal de **+** e uma seta apontando para baixo, como mostra a imagem abaixo:

<div><img src="https://i.imgur.com/hQ2csFo.png" title="source: imgur.com" /></div>

4. Clique na seta apontando para baixo e no menu que será aberto, clique na opção **Select Default Profile (Selecione o Perfil Padrão)**.

<div align="center"><img src="https://i.imgur.com/nlQYFaX.png" title="source: imgur.com" /></div>

5. No menu suspenso que será exibido logo abaixo da **Barra de Menus** do Visual Studio Code, clique na opção **Git Bash**, como mostra a imagem abaixo:

<div align="center"><img src="https://i.imgur.com/81kHNE7.png" title="source: imgur.com" /></div>

7. Feche a Janela do Terminal e abra novamente através do menu **Terminal 🡪 New Terminal (Terminal 🡪 Novo Terminal)**. 
8. Observe que será aberta a janela do Terminal **Git Bash**, ao invés da janela do **Powershell**.

<div><img src="https://i.imgur.com/wBU8rTx.png" title="source: imgur.com" /></div>

<br />

> [!IMPORTANT]
>
> O uso do **Git Bash** é recomendado no Windows por manter maior compatibilidade com comandos utilizados em ambientes Linux e macOS.

<br />

> [!TIP]
>
> Nos próximos projetos criados no **Visual Studio Code**, não será necessário realizar novamente a configuração do **Terminal**, pois as definições já permanecerão salvas no ambiente de desenvolvimento.

<h2>👣 Passo 04 - Instalando Extensões no Visual Studio Code</h2>



Vamos instalar algumas extensões no **Visual Studio Code** que irão auxiliar no processo de desenvolvimento do nosso **projeto web** utilizando HTML, CSS e JavaScript.  

As extensões adicionam novas funcionalidades ao editor, tornando o trabalho mais produtivo e facilitando a visualização e escrita do código.

Na tabela abaixo, você encontra a lista de extensões que serão utilizadas ao longo do projeto:

| Extensão             | Descrição                                                    | Link                                                         |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Live Server**      | Permite visualizar páginas HTML diretamente no navegador, com atualização automática sempre que o código for salvo. Esse recurso simula um ambiente real de execução, semelhante a um website publicado. | <a href="https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer" target="_blank"><img src="https://i.imgur.com/AXKrwP5.png" title="Live Server" width="40px"/></a> |
| **HTML CSS Support** | Adiciona suporte aprimorado a HTML e CSS, incluindo sugestões automáticas, reconhecimento de classes e IDs definidos no CSS e melhoria na produtividade durante a escrita do código. | <a href="https://marketplace.visualstudio.com/items?itemName=ecmel.vscode-html-css" target="_blank"><img src="https://i.imgur.com/7IdCTXz.png" title="HTML CSS Support" width="40px"/></a> |

<br />

1. Para iniciar a instalação, clique no **link da extensão** disponível na coluna **Link** da tabela acima.
2. Ao clicar no link, você será redirecionado para a página da extensão no **Visual Studio Marketplace**. No exemplo abaixo, vemos a página da extensão **Live Server**.

<div><img src="https://imgur.com/oO43j7a.png" title="source: imgur.com" /></div>

3. Na página da extensão, clique no botão **Install**.

<div><img src="https://imgur.com/4bOzK0S.png" title="source: imgur.com" /></div>

4. Em seguida, será exibida uma mensagem perguntando se você deseja abrir o link no **Visual Studio Code**.

<div><img src="https://imgur.com/CjiEVdE.png" title="source: imgur.com" /></div>

5. Marque a opção **“Sempre permitir que o marketplace.visualstudio.com abra este tipo de link no app associado”** e clique em **Abrir Visual Studio Code**.
6. A página da extensão será aberta diretamente no Visual Studio Code. Clique no botão **Install** para concluir a instalação.

<div><img src="https://imgur.com/S6i560q.png" title="source: imgur.com" /></div>

7. Repita esse mesmo processo para instalar as demais extensões listadas.

<h2>👣 Passo 05 - Criar uma conta no Imagekit</h2>



O **ImageKit.io** é um serviço de gerenciamento de imagens on-line, que permite compartilhar imagens gratuitamente em websites e Redes Sociais. Ele fornece otimização inteligente de imagens em tempo real, incluindo o redimensionamento e o corte, além de permitir a integração com diversas Linguagens de Programação.

O Plano Gratuito oferece:

- 20 GB de largura de banda;
- 20 GB de armazenamento de mídia
- 1000 vídeos e 500 unidades de extensão.
- Requisições ilimitadas
- Transformações de imagem ilimitadas
- Conjunto completo de recursos de gerenciamento de imagem, vídeo e mídia
- Suporte por e-mail

<br />

> [!WARNING]
>
> Os valores e limites do plano gratuito podem sofrer alterações conforme a política do ImageKit.

<br />

1. Para criar uma conta no **Imagekit**, clique no link abaixo:

<br />

<div align="left"><img src="https://i.imgur.com/wWJGh6U.png" title="source: imgur.com" width="4%"/> <a href="https://imagekit.io/" target="_blank"><b>Imagekit.io</b></a></div>

<br />

2.  Será aberta a página abaixo. Clique no botão **Sign up** para criar a conta:

<div><img src="https://i.imgur.com/m98qv7B.png" title="source: imgur.com" /></div>

3. Crie uma nova conta utilizando o seu e-mail do Google, clicando no botão **Fazer logon com o Google**

<div><img src="https://i.imgur.com/AdH1bwv.png" title="source: imgur.com" /></div>

4. Ao concluir o processo de autenticação com o Google, você será redirecionado para a página de Boas-vindas, Altere a opção **Region** para **North Virginia** e clique no botão **Next**:

<div><img src="https://i.imgur.com/YU63O7q.png" title="source: imgur.com" /></div>

5. Na sequência, você será redirecionado para o Dashboard do Imagekit:

<div><img src="https://i.imgur.com/8FjTdCJ.png" title="source: imgur.com" /></div>

<div><img src="https://i.imgur.com/uzuKq9a.png" title="source: imgur.com" /></div>

7. Selecione e arraste as imagens que você deseja enviar para o Imagekit e solte dentro do Media Library.

> [!WARNING]

8. Na sequência será aberta a janela de confirmação das imagens que serão enviadas para o Imagekit. Clique no botão **Upload file** para confirmar.

## 🔑**Pontos chave:**

1. Um **Ambiente de Desenvolvimento Integrado (IDE)** reúne ferramentas essenciais para criar aplicações, como editor de código, terminal, depurador e integração com controle de versão.
2. O **Visual Studio Code** é um editor de código extensível, amplamente utilizado no desenvolvimento Frontend com **HTML, CSS e JavaScript**.
3. O Visual Studio Code possui **terminal integrado**, permitindo executar comandos e ferramentas diretamente no editor.
4. O uso de **extensões** aumenta a produtividade, facilitando visualização, escrita e testes de código.
5. A organização do projeto em **pastas bem definidas** é essencial para manutenção e escalabilidade.
6. Serviços externos como o **ImageKit** auxiliam no gerenciamento e otimização de imagens, melhorando desempenho de websites.
7. É fundamental respeitar **direitos autorais** ao utilizar imagens e vídeos em projetos web.
