<h1>Projeto 01 - Portfólio - Enviar E-mail pelo Formulário</h1>



Através dos **Eventos da Linguagem JavaScript**, vamos tornar o nosso formulário **funcional**, configurando-o para **enviar um e-mail automaticamente** para o seu endereço de e-mail com as informações preenchidas pelo usuário.

Para realizar o envio das mensagens, utilizaremos o serviço gratuito **FormSubmit**, que permite o envio de dados de formulários HTML por e-mail **sem a necessidade de um Backend**. Com o auxílio dos eventos JavaScript, será possível **capturar, validar (função já implementada) e controlar o envio dos dados**, garantindo uma melhor experiência para o usuário e maior controle sobre o comportamento do formulário.

<br />

<h2>1. Form Submit</h2>



O **FormSubmit** é uma ferramenta que simplifica o envio de dados de formulários HTML **diretamente para o seu e-mail**, sem a necessidade de configurar uma API ou utilizar código de servidor, como PHP ou JavaScript no Backend — abordagens que, em muitos casos, são bloqueadas ou limitadas por serviços de e-mail.

<br />

<div align="left"><img src="https://i.imgur.com/wKHNfGi.png" title="source: imgur.com" width="4%"/> <a href="https://formsubmit.co/" target="_blank"><b>Form Submit</b></a></div>

<br />

O **FormSubmit** é simples de utilizar e não exige configurações complexas nem a criação de conta. De forma geral, o funcionamento segue os passos abaixo:

1. **Conectar o formulário**
    No atributo `action` do formulário HTML, informe a URL do FormSubmit junto com o seu endereço de e-mail:
    `https://www.formsubmit.co/seu_email@email.com.br`.
2. **Adicionar atributos aos campos do formulário**
    Todos os campos do formulário (`<input>`, `<select>`, `<textarea>`, etc.) devem possuir o atributo `name`.
    Os nomes mais comuns são: `name` (nome), `email`, `subject` (assunto) e `message` (mensagem).
3. **Enviar e confirmar**
    Envie o formulário uma primeira vez para ativar o serviço. Você receberá um e-mail de confirmação para validar o endereço informado. A ativação ocorre ao clicar no link enviado.
4. **Adicionar o código de ativação na URL**
    Após a confirmação, substitua o e-mail informado no atributo `action` pelo **código de ativação** recebido:
    `https://www.formsubmit.co/seu_codigo_de_ativacao`.

Além do envio básico, o **FormSubmit** oferece recursos adicionais, como:

- Definir uma URL de redirecionamento após o envio do formulário (página success);
- Personalizar o assunto do e-mail;
- Enviar cópias para outros endereços;
- Desativar o captcha padrão, entre outros.

A seguir, vamos configurar o **FormSubmit na prática**, integrando-o ao nosso formulário e controlando o envio com eventos JavaScript.

<br />

<h2>👣 Passo 01 - Atualizar o Formulário na Página index</h2>



1. Abra a página **index.html**
2. Localize o trecho de código abaixo:

<div align="center"><img src="https://i.imgur.com/CRF7pK2.png" title="source: imgur.com" /></div>

3. Substitua a **linha 132**, pelo trecho de código abaixo:

```html
<form id="formulario" action="https://formsubmit.co/seu_email@email.com" method="POST">
```

*Na propriedade `action`, onde está escrito **seu_email@email.com**, substitua pelo endereço do seu e-mail pessoal.*

> A propriedade **`action`** do elemento `<form>` do HTML define **para onde os dados do formulário serão enviados** no momento da submissão, ou seja, quando o usuário clica no botão **Enviar**. Em termos práticos, ela indica a **URL do servidor responsável por receber e processar os dados** informados no formulário.
>
> No contexto deste projeto, a propriedade `action` aponta para o servidor do serviço **FormSubmit**, que recebe os dados enviados pelo formulário e se encarrega de **encaminhar a mensagem diretamente para o seu e-mail**, sem a necessidade de implementação de código backend.
>
> Além da propriedade `action`, o elemento `<form>` também utiliza a propriedade **`method`**, que define **como os dados serão enviados** para o servidor. Os métodos mais comuns são:
>
> - **`GET`**: envia os dados pela própria URL, tornando-os visíveis. É indicado apenas para consultas simples e **não recomendado** para envio de informações sensíveis.
> - **`POST`**: envia os dados no corpo da requisição HTTP, de forma mais segura e organizada. É o método **mais utilizado para formulários**, especialmente quando envolvem envio de mensagens, senhas ou dados pessoais.
>
> Em geral, ao utilizar serviços como o **FormSubmit**, recomenda-se o uso do método **POST**, pois ele garante maior segurança e melhor tratamento das informações enviadas pelo formulário.

4. Na **linha 133**, adicione o trecho de código abaixo:

```html
<input type="hidden" name="_next" value="http://localhost:5500/success.html">
<input type="hidden" name="_captcha" value="false">
```

O trecho de código acima adiciona **dois inputs do tipo `hidden`**, ou seja, campos ocultos que **não são exibidos ao usuário**, mas que possuem valores predefinidos e são enviados ao servidor juntamente com os dados preenchidos no formulário.

- O primeiro input, denominado **`_next`**, define **qual página será exibida após o envio do formulário ser concluído com sucesso**. Dessa forma, é possível redirecionar o usuário para uma página de confirmação, agradecimento ou qualquer outra página desejada. Em nosso projeto, será a página **`success.html`**.
- O segundo input, chamado **`_captcha`**, indica que o usuário **não precisará resolver um captcha antes do envio do formulário**, pois o valor `false` desativa essa verificação. Essa configuração simplifica a experiência do usuário, eliminando uma etapa adicional, sem comprometer o funcionamento do serviço de envio de e-mails.

<br />

> O **CAPTCHA** (*Completely Automated Public Turing Test to Tell Computers and Humans Apart*) é um mecanismo de **segurança digital** utilizado para diferenciar usuários humanos de *bots*, que são programas automatizados capazes de executar ações repetitivas na internet, como envio de spam ou tentativas de acesso indevido.
>
> Esse recurso funciona por meio de **desafios simples para humanos**, mas **difíceis de serem resolvidos por máquinas**, ajudando a proteger formulários, sistemas e serviços online contra usos maliciosos.
>
> <div align="center"><img src="https://i.imgur.com/2sgPeyf.png" title="source: imgur.com" /></div>
>
> Existem diferentes tipos de CAPTCHA, entre os mais comuns destacam-se:
>
> 1. **Texto distorcido**
>     O usuário deve identificar e digitar corretamente um conjunto de letras e números apresentados de forma distorcida.
> 2. **Seleção de imagens**
>     O usuário precisa selecionar imagens que correspondam a uma instrução específica, como identificar objetos ou cenários.
> 3. **ReCAPTCHA**
>     Desenvolvido pelo Google, pode variar desde a simples marcação da opção *“Não sou um robô”* até desafios visuais mais complexos, dependendo do nível de suspeita detectado.
>
> De forma geral, o uso do CAPTCHA contribui para a **prevenção de spam**, **ataques automatizados** e **envio indevido de formulários**, aumentando a segurança das aplicações web sem exigir grandes configurações técnicas.
